GIT

O git é um sistema de controle de versão distribuído.

Comandos do git

  • git init : inicializa um repositório git
  • git status
  • git add arquivo.txt : Adiciona no stage
  • git commit -m "Comentário" : Cria um commit no seu repositório
  • git log : exibe os commits da branch atual do repositório local
  • git switch branch: muda de branch
  • git switch -c cria-nova-branch
  • git diff: exibe a diferença do commit apontado por HEAD e worktree
